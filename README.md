# Ecommerce Data Science Project

## Project Overview
This project analyzes online retail transaction data to identify sales trends, top-performing products, high-revenue countries, and valuable customers.

## Objectives
- Clean and preprocess retail transaction data
- Analyze sales and customer purchasing patterns
- Identify top products and countries by revenue
- Visualize sales trends using Python
- Generate actionable business insights

## Dataset
The project uses the **Online Retail dataset** from the UCI Machine Learning Repository.

- **Source:** https://archive.ics.uci.edu/dataset/352/online+retail
- **Original records:** 541,909 transactions
- **Time period:** December 2010 – December 2011
- **License:** CC BY 4.0

Download the original dataset from the source above. The cleaned CSV is not included in this repository because of file-size limitations.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Project Workflow
1. Load and inspect the dataset
2. Check missing values and duplicate records
3. Clean invalid quantities and prices
4. Calculate sales using Quantity × UnitPrice
5. Analyze top products and countries
6. Analyze customer sales
7. Visualize sales trends
8. Summarize business insights

## How to Run
1. Download the dataset from the UCI source linked above.
2. Open `Ecommerce_Data_Science_Project.ipynb` in Google Colab.
3. Upload the downloaded Excel file when prompted by the notebook.
4. Run the notebook cells in order.

## Output
The project produces cleaned transaction data, sales summaries, customer and country analysis, and visualizations to support business decisions.
